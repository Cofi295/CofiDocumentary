# Design System Skill
Source: b:\.agents\skills\design-system\SKILL.md

Core Methodology:
- Three-Layer Structure:
  1. Primitive (raw values e.g. --co-slate-900, --co-cyan-400)
  2. Semantic (purpose aliases e.g. --surface-card, --border-focus)
  3. Component (component-specific e.g. --accordion-border, --canva-stage-bg)
- Component spec pattern: Default, Hover, Active, Disabled
- Never use raw hex in components, always reference tokens
- Token compliance and accessibility standards
